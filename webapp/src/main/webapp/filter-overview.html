Filtersuche
Die Groß- und Kleinschreibung wird bei der Suche ignoriert. Es ist auch eine Suche basierend auf den Spalten möglich. Syntax:
key:value
key:value;key:value;...
value
value;value;value;...
Es stehen folgende keys zur Auswahl: id, title, editor, creator.
